    File Upload Import

    Upload CSV or XLSX files with slab metadata:

    • Supports .csv and .xlsx file formats
    • Required column: Name (or Title, Slab_Name)
    • Optional: StoneType, Supplier, Finish, Thickness, Color, Length, Width, Location, Status, Quantity, Cost, Price
    • Include SlabID column to update existing slabs
    Column Mapping

    Headers are mapped automatically (case-insensitive):

    • Name, Title, Slab_Name → Slab Name
    • StoneType, Type, Material → Stone Type
    • SquareFeet, SqFt, Area → Square Feet
    • Unmapped columns are stored in extra_json
